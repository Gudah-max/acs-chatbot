TROUBLESHOOTING
=============================================================
 
PROBLEM: The chat bubble does not appear on the website

     for errors. Confirm the Railway URL is correct with no trailing slash.
 
PROBLEM: Amara says "I don't know" to basic questions
FIX: The answer is probably missing from acs-knowledge.txt. Add it in Q: / A: format
     and redeploy.
 
PROBLEM: API errors / "something went wrong" messages
FIX: Check your ANTHROPIC_API_KEY is set correctly in Railway Variables.
     Check the Railway logs for the exact error message.
 
PROBLEM: The widget looks broken on mobile
FIX: Claude Code built mobile responsiveness in — if it looks off, share a screenshot
     and ask Claude Code to fix the CSS for screens under 480px.
 
PROBLEM: Fees are wrong or out of date
FIX: Open acs-knowledge.txt, find Section 5 (Fees), update the numbers, save, push to
     GitHub. Railway will redeploy automatically.
